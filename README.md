# 🛠 Workshop de Programación: Herencia Múltiple en Python

## 🎯 Objetivos

- Comprender el concepto de herencia múltiple.
- Aplicar herencia múltiple en Python con ejemplos prácticos.
- Analizar ventajas, problemas comunes y buenas prácticas.
- Fomentar la resolución de problemas colaborativos.

---

## 🧩 Estructura del Workshop

### 1. Inicio (15 min)
- Presentación del tema y ejemplo introductorio.
- Explicación del orden de resolución de métodos (MRO).

### 2. Desarrollo (60 min)
- Actividad en grupo: Implementación de un caso práctico con herencia múltiple.
- Análisis de conflictos de métodos y uso de `super()`.

### 3. Break (15 min)
- Pausa breve para descansar.

### 4. Cierre (30 min)
- Puesta en común por grupos.
- Reflexión sobre ventajas y desafíos de la herencia múltiple.
- Recomendaciones del docente.

---

## 💻 Actividades

Ver la carpeta `src/` para ejemplos y desafíos:

- `ejemplo_basico.py`: uso simple de herencia múltiple
- `desafio_principal.py`: actividad principal del taller
- `resolucion_mro.py`: cómo Python resuelve los métodos en la jerarquía

---

## ✅ Requisitos

- Python 3.7+
- Editor de código (VSCode recomendado)

Para ejecutar los archivos:

```bash
python src/ejemplo_basico.py
```
